Privacy Policy

Last updated: 2026-10-04

"My rclone Drive Sync" is a personal Google OAuth client used by one person to run rclone on their own devices. This page explains how it handles Google user data.

Data the app accesses

When I authorize the app, it can access files in my own Google Drive, within the Drive permission (scope) I choose when configuring rclone. It does not access any other Google service.

How the data is used

Files are transferred directly between Google Drive and my own computer for backup, sync, and copy purposes. Data is not used for advertising, analytics, profiling, or training of AI or machine-learning models.

Storage

The OAuth token issued by Google is stored only in rclone's configuration file on my own devices. There is no server operated by me, and no Google user data is stored anywhere else.

Sharing

I do not share, sell, or transfer Google user data to any third party. No one other than me has access to it.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Deleting rclone's configuration file removes the stored token.
